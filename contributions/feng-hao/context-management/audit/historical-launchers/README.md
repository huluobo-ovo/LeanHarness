# Historical Launchers

These archived launchers document how the submitted experiments were run. They contain original local absolute paths and are not portable launch scripts. Required uv binaries and dependency caches are not bundled. Use the pinned team environment and the general entry points in `docs/scheme-a/REPRODUCE.md` for a separately authorized reproduction. Do not execute these launchers merely to merge or inspect results.

For this English delivery copy, console messages and the human-readable retry-authorization description were translated. Two historical evidence filenames were translated to English, and the delivery-copy preflight reference was updated accordingly. These presentation changes do not represent the exact bytes of the scripts executed during the experiments. Execution-time hashes in the preserved trial and batch provenance refer to the original artifacts. Experimental records and local originals have not been altered.
